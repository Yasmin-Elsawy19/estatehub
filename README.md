# EstateHub 🏡

A modern and responsive real estate platform for discovering properties across Egypt.

## Overview

EstateHub helps users explore properties for sale and rent through a clean, user-friendly interface. The platform supports Arabic and English, with full RTL/LTR layout support.

## Features

- Browse featured properties.
- Search properties by location and type.
- Explore property details.
- Add properties to favorites.
- Buy and rent property options.
- Arabic and English language support.
- Responsive design for different screen sizes.
- Light and dark mode.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- Context API
- Axios
- i18next
- Framer Motion
- Lucide React

## Project Status

Currently under development.

**Note:** This is a frontend demo project using mock property data. It does not represent real estate listings.

## Getting Started

```bash
git clone https://github.com/Yasmin-Elsawy19/estatehub.git
cd estatehub
npm install
npm run dev
```
